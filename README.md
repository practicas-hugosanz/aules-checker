# Aules

App para Windows que lee Aules (Moodle de FP de la GVA) y te enseña en una sola página tus tareas, exámenes, notas, mensajes, foros, materiales y horario, con avisos y recordatorios.

## Instalar

Descarga [Instalar Aules.bat](https://github.com/practicas-hugosanz/aules-checker/raw/main/para_compartir/Instalar%20Aules.bat) y ábrelo con doble clic. Si Windows avisa de que protegió el equipo, pulsa «Más información» y «Ejecutar de todas formas».

Cuando haya una versión nueva, la app te avisará con la lista de cambios y un botón «Actualizar».

## Privacidad

Todo se queda en tu PC. La contraseña solo se guarda, cifrada con tu usuario de Windows, si marcas la casilla al iniciar sesión.
